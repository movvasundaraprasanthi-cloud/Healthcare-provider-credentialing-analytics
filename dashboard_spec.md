# Dashboard Build Specification

## Page 1: Executive Overview
- KPI Cards: Total Providers, Completed, Pending, Avg Turnaround, SLA Breaches
- Line Chart: Monthly intake volume
- Column Chart: Status distribution
- Bar Chart: Completed vs Pending by state

## Page 2: Backlog & Aging
- Stacked bar: Pending cases by state and status
- Matrix: Analyst vs Status
- Aging bucket bar chart
- Table: Top 20 oldest pending files

## Page 3: Quality & Exceptions
- Donut chart: Missing documents / verification issues / committee review
- Column chart: Exception count by state
- Table: Rejected and on-hold cases

## Page 4: Productivity
- Analyst productivity scorecard
- Completed cases by analyst
- Avg turnaround by analyst
- Intake source contribution
