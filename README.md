# Healthcare Provider Credentialing Performance Analytics

## Business Problem
Healthcare credentialing teams need clear visibility into provider onboarding volume, turnaround time, backlog aging, SLA risk, and state-wise performance. Operational leaders often struggle to identify where pending files are accumulating, which analysts or states have the highest delays, and what document or verification issues are slowing network readiness.

## Objective
Build an analytics solution that helps leadership monitor:
- Provider credentialing volume by state, analyst, and specialty
- Completion trends and pending backlog
- Average turnaround time vs SLA target
- Aging buckets for pending files
- Exception trends such as missing documents and verification issues
- Productivity and throughput by analyst

## Tools Used
- SQL
- Power BI
- Excel / CSV
- GitHub

## Dataset
This starter project includes a realistic sample dataset:
- 320 provider credentialing records
- Multi-state workflow coverage
- Status tracking, turnaround time, SLA target, issue flags, and analyst assignment
